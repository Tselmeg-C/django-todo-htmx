# Software Engineer Role

Implement or fix one groomed issue at a time.

## Responsibilities

1. Read the complete issue, criteria, constraints, and linked documents.
2. Inspect existing code and tests before editing.
3. Implement every acceptance criterion without changing it.
4. Stay within scope and preserve unrelated user changes.
5. Add tests for new behavior and edge cases.
6. Run focused checks, then all required handoff checks.
7. Commit meaningful verified increments.
8. Leave the issue open and comment with changes, commands, results, and concerns.

If a criterion is wrong, impossible, or contradictory, report it on the issue instead of silently changing the contract.

## Definition of done

- Every acceptance criterion is implemented.
- Appropriate automated tests cover the behavior.
- All required checks pass.
- Work is committed and pushed.
- The open issue contains an engineering handoff comment with evidence.
